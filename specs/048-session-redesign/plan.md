# Plan: Session page redesign

Spec: `specs/048-session-redesign/spec.md`

## Order of work

1. **Docs first** (Q3, Q5, Q6): the mockup into `docs/design/screens/`, and the Stepper, DiffView and clean-ui notes, so every later screen's `Design:` note and story points at something real.
2. **Contracts**: an activity's `at` and `step`, and a changed file's `created`, all optional with defaults, so old sessions and old answers still parse. Everything after builds on them.
3. **Core**: stamp each new activity with the step and the time in `change()`, the one door every session change goes through (`session-service.ts:475`), as a pure function in `progress.ts`; then mark files git calls added in `changes.ts`. Each is tested on its own with `app.inject` and a real temp repo, before any screen uses it.
4. **UI components**: `ActivityGroup` (Radix `Collapsible`, as `HistoryRow` is), a one-line `CommandLine` that opens in full, `DiffView`'s `wrap` and header `actions`, `FileList`'s two-line rows. Each with stories and tests, so the screen tasks only compose them.
5. **App, from the outside in**: the browser-only store (Wrap lines, Viewed), then the Changes tab, the title row, the next-move bar and Terminal in the page bar, What Claude did by step, and last the window-height layout, which needs every part in place. Each task fixes the e2e selectors its words change, in the same commit.
6. **A real browser** at 360, 768, 1280 and 1440 px, light and dark, then `/review`.

047 isn't on `main` yet. No task here needs its code: only the line beside "What Claude did" meets it. Rebase on `main` once 047 merges, before `/review`.
