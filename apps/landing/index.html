How it works

Anything to a pull request. Four steps.

  1. Pick the work

    A ticket, a pull request, a Slack or Discord thread, or your own words.

  2. It gets a worktree

    A fresh branch. Your own checkout stays untouched.

  3. Your rules decide

    Allow, ask or block each kind of call. It asks you when a choice is yours.

  4. Ship it

    Open the pull request in one click, then tell the thread it's up.

Get started

Running in a few minutes.

Clone orynx-ai/orynx on macOS or Linux. You need:

  • Node 24, or nvm to install it
  • Claude Code or Codex, signed in
  • A Jira API token, and gh or a GitHub token
  • Slack or Discord, if you want their messages too

Then open http://127.0.0.1:4317 to pick your name and password.

FAQ

Questions, answered.

Does my code leave my computer?

Orynx has no cloud. Your coding agent reads the files a task needs through your own login, exactly as it does in your terminal. Jira, GitHub, Slack and Discord are called with your own tokens.

Which agent account does it use?

The ones already on your computer. Claude uses Claude Code's login: a claude.ai account, an API key, Amazon Bedrock or Google Vertex. Codex uses its own: ChatGPT or an API key. Orynx needs no key of its own, and you pick the agent for each task.

Can the agent push or open a pull request by itself?

Only if you allow it. A fresh Orynx never pushes. Pick Hands-off in Settings › Coding agent, or set Push the branch and Open a pull request to Allow.

Does it post to GitHub, Slack or Discord without me?

No. A review, replies to reviewers and the note in a thread go out only when you press Post review, Post replies or Post reply. Until then they stay in Orynx, for you to keep, edit or drop.

Does it change my working copy?

No. Every session works in its own git worktree on its own branch.

Can I use it from my phone?

Yes, on the same wifi. Open https://orynx.local, enter your Orynx password once, and trust Orynx's certificate from http://orynx.local/orynx-ca.crt. Your code and tokens stay on the computer that runs Orynx.

What comes next?

More connectors and coding agents. Each is a small adapter that gets the same screens and permissions, the way Slack, Discord and Codex just did.
